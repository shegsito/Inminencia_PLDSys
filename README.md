## About
The objective of this project is to create a possibility of the implementation of technology and automatization of financial processes that may otherwise be time consuming. This is not only to optimize the processes, but to complete them with utmost efficiency and proficiency considering the legal concepts that will be considered.

Using an MVC structure with express, NodeJS and pnpm, this project was developed to the best of our abilities. 

## Usage
Before you begin installing, it is important to have <a href="https://nodejs.org/en">Node.js 20 o superior</a> and <a href="https://git-scm.com/">Git</a> installed.

Once you have these installed, run the following commands:

```bash
git clone https://github.com/shegsito/Inminencia_PLDSys.git
cd Inminencia_PLDSys
pnpm install
```
To see the project running locally, you can use:
**http://localhost:3001/**

You may not be able to run the project smoothly considering the lack of our database. You *will* be able to see the code and structure of the project.
